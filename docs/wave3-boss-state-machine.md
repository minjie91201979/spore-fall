# 《孢城 SPORE FALL》Wave 3 — Boss「织理者 Loom Weavers」三阶段状态机规格

> 对应设计文档章节：§11.16 Wave 3 Boss 机制

## 一、Boss 概述

| 项 | 值 |
|---|---|
| 名称 | 织理者 / Loom Weavers |
| behavior | `"boss"`（复用现有 boss 框架，额外挂载 `loom` 规则节点） |
| HP 范围 | 基础 600 × hp_mult（随 boss 轮次递增） |
| 视觉色轴 | 荧光橙主体 + 电蓝反射柱 + 白噪灰背景线 |
| 入场条件 | WaveMode.wave3_delay（默认 45s + wave2_delay 之后） |
| 胜利目标 | 击溃 → `GameState.objective_text = "目标　区域已肃清"` |

## 二、三阶段 HP 阈值与规则覆盖

| 阶段 | HP 区间 | 触发方式 | 规则覆盖 | 场景变化 |
|---|---|---|---|---|
| P1 「初始织造」 | 100% → 66% | 开场默认 | 无 | 标准竞技场 |
| P2 「镜像域展开」 | 66% → 33% | 自动切换 | 新增「镜像反射柱」× 3（可反弹玩家位移） | Arena 中央地面出现蓝色发光阵纹 |
| P3 「终末编织」 | 33% → 0% | 自动切换 | 伪晶体密度 × 4、镜影孢刷怪频率 × 2 | 反射柱转为高频闪烁红色警告 |

**状态转换不可逆**（一旦进入 P2 不会退回 P1），便于 AI 动画只做 forward tick。

## 三、技能优先级与冷却互斥表

### 基础结构（所有阶段通用）
```
每 5.5s 检查一次技能可用（skill_interval）
候选列表 = {未正在施放 且 _last_skill != N}
从候选中随机选一个（等权），若全满则跳过本轮
施放结束后 _last_skill = N，skill_cd 重置
```

### 各阶段技能表

#### P1「初始织造」— 2 技能轮换
| 优先级 | 技能名 | 行为描述 | 前摇可读性 | 反制窗口 | 音效提示 |
|---|---|---|---|---|---|
| 1 | 纺线连射 | 向玩家当前位置发射 5 发扇形针（spread=30°） | 胸部红灯亮 0.8s | 侧身躲开扇形区 | "spin_wind" |
| 2 | 织网封锁 | 在玩家脚下前方 200px 处降下一根「线」（Line2D Area2D，持续 4s） | 线从地面缓慢升起 0.4s（亮度由 0→1） | 跳线或侧移出区域 | "web_drop" |

> P1 无「克隆降临」和「覆写协议」——保持节奏让玩家长达熟悉。

#### P2「镜像域展开」— 新增第 3 技能
| 优先级 | 技能名 | 行为描述 | 前摇可读性 | 反制窗口 |
|---|---|---|---|---|
| 1（最高） | 克隆降临 ⭐ | 在场地上生成 2 只「镜影孢幻影」假单位；受击不扣血但触发攻击特效；2s 后自毁并各自生成一颗伪晶体 | 屏幕四周紫色闪边 0.3s + 音效 "clone_summon" | 无视打爆避免伪晶体扩散 |
| 2 | 纺线连射（P1 保留） | 同上 | 同上 | 同上 |
| 3 | 织网封锁（P1 保留） | 同上 | 同上 | 同上 |

**P2 新增场地效果「镜像反射柱」**：
- 生成 3 根静态 Area2D（位于 Arena 对角线对称点）
- 玩家撞上去会被弹到**对角线对映点**（`mirror_pos = 2*pillar.pos - player.pos`）
- 视觉：蓝色半透明圆柱体 + 轻微脉动光效（Shader 或 Sprite2D 缩放循环）
- **策略张力**：玩家被逼向边界 vs 利用折射绕过 Boss 攻击线

#### P3「终末编织」— 新增第 4 技能 + 全局规则
| 优先级 | 技能名 | 行为描述 | 前摇可读性 | 反制窗口 |
|---|---|---|---|---|
| 1 | 覆写协议 ⭐⭐ | 冻结场上全部 pickup（含晶体的磁吸暂停）3 秒 | 全局 UI 变灰 0.3s + 低频嗡鸣 "rewrite" | 提前收走晶体入包 |
| 2 | 克隆降临（P2 保留） | 同上，幻影数量加为 3 | 同上 | 同上 |
| 3 | 纺线连射（P1 保留） | 弹幕数从 5 → 8 发 | 同上 | 同上 |
| 4 | 织网封锁（P1 保留） | 同时下 2 根线（间隔 1s） | 同上 | 同上 |

**P3 全局规则覆盖**：
- 伪晶体 spawn_rate × 4（通过修改 Spawner 权重临时注入）
- 镜影孢刷新间隔 × 0.5（`WaveMode` 控制）
- 反射柱闪烁频率 × 3（视觉压迫感）

## 四、Boss 特殊机制：「织理者的线」

> P2 起生效，贯穿整场战斗的动态地形

**数据结构**：
```gdscript
class_name LoomThread:
    var start: Vector2          # 起点（Arena 固定锚点）
    var end: Vector2            # 终点（随时间向中心收缩）
    var life: float = 8.0       # 存在时长
    var shrink_rate: float = 12.0  # px/s，两端同步向中点靠拢
```

**生命周期**：
- P2 开场时 spawn 2 条交叉线（对角线方向）
- 每条线持续 8s，期间玩家不能穿越（Area2D 碰撞）
- 收缩至最短距离 60px 后消失
- 消失瞬间在消失点生成 1 颗伪晶体（惩罚未及时撤离的玩家）

**反制解读**：
- 玩家可以故意站在「即将消失的线上」，等它缩到安全距离后再穿过 —— 高风险高回报走位博弈
- 伪晶体作为惩罚资源，逼迫玩家在躲避线的同时处理真假混合的拾取压力

|---|---|---|---|
| 待机巡逻 | `loop` | frame_001~004 | 12 |
| 纺线连射前摇 | `act1_spin_wind` | frame_001~004 | 12 |
| 织网封锁前摇 | `act2_web_drop` | frame_001~004 | 12 |
| 克隆降临前摇 | `act3_clone_summon` | frame_001~004 | 12 |
| 覆写协议前摇 | `act4_rewrite_protocol` | frame_001~004 | 12 |
| 受击硬直 | `hit` | frame_001~003 | 12 |
| 死亡爆发 | `death` | frame_001~006 | 12 |

**帧约定**：
- loop 始终从「neutral stance」开始，压缩→伸展→回到 neutral 保证无缝衔接
- act 类 clip 必须包含「蓄力峰值」在第 2/3 帧，让玩家读前摇有明确参照
- 禁止任何 scale/rotation/modulate 写入（交给 FramePlayer.gd 管控）

## 六、验收标准（DoD）

- [ ] P1 两个技能各至少跑 1 轮，前摇灯光 + 音效正确触发
- [ ] HP < 66% 自动切 P2，Arena 中央反射柱可见且 Player 撞柱后 teleport 到对映点
- [ ] P2 克隆降临召唤的幻影受击无伤害数字飘字，2s 后自毁并 spawn false crystal
- [ ] HP < 33% 自动切 P3，场上伪晶体总量在短时间内 ≥ 10 颗（验证 density boost）
- [ ] 织理者的线在 P2/P3 均能 spawn、收缩、消失；消失点 spawn false crystal
- [ ] 三个阶段切换时无脚本错误、无状态残留
- [ ] `probe_boss_w3.gd` 14 项断言全过（状态机时序 / 技能冷却互斥 / 阶段 HP 阈值 / 反射柱 teleported / 线 spawn-count）
